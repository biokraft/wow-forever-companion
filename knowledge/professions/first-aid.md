# First Aid (Horde)

## Forever changes

- **Healing potions moved from Alchemy to First Aid**: anyone can make them. Big for a warrior with no self-heal beyond Victory Rush.
- Camp object **First Aid Kit** (First Aid 20): 3 Linen Bandage + 1 Refreshing Spring Water. Stamina buff like Power Word: Fortitude (doesn't stack with it). Recipe from the "Camping 101: First Aid" starter quest or any First Aid trainer. Tier 2 Toxin Study, tier 3 Plague Doctor's Laboratory.
- First Aid is in its 1.12 form, including the Triage quest for Artisan.
- First Aid gives no Legacy Points (only crafting professions do; see `forever-rules.md`).

## Materials on the Horde 1–30 route

- Linen: humanoids in Durotar and the Barrens (quilboar, centaurs, Razormane): model memory, `scope: classic`, unverified.
- Wool: humanoids in the 20s (Stonetalon, Ashenvale, Hillsbrad, Thousand Needles): model memory, unverified.
- Peacebloom (for potions): herb; buy on the AH if not an herbalist.
- Linen is shared with Engineering (28–45 for 1–150 there). Budget both: ~215 Linen total.

## Advice

- Advisor suggestion (not from a source): keep First Aid in step with character level so bandages match HP: Heavy Linen by ~15, Wool by ~25.
- Place the First Aid Kit camp object at 20 skill for +Stamina at the campfire.
