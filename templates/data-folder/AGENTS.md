# My WoW: Forever companion folder

This folder belongs to Forever Companion. `wowf sync` keeps `characters/` up to date from the
ForeverLog addon; plans pushed to the in-game panel are copied to `plans/`; your game plan
is kept in `gameplans/`; research the companion did for you is cached in `knowledge/`.
Don't hand-edit `characters/` or `gameplans/`.

For any game question (leveling, quests, gear, talents, professions, "what now"), use the
`wow-advisor` skill. For a quick look at how you're doing, use `wow-checkin`. To set up or
change your game plan, use `wow-gameplan`.
